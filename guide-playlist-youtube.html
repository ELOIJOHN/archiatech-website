📺 GUIDE PLAYLIST YOUTUBE

Ajouter Votre Playlist YouTube

Guide étape par étape pour intégrer votre playlist YouTube sur votre site ArchiAtech.

1

Créer votre Playlist YouTube

Commencez par créer une playlist sur YouTube avec vos vidéos ArchiAtech.

📋 Instructions détaillées :

  1. Allez sur youtube.com et connectez-vous
  2. Cliquez sur "Bibliothèque" dans le menu de gauche
  3. Cliquez sur "Créer une playlist"
  4. Donnez un nom à votre playlist (ex: "ArchiAtech - Solutions IA")
  5. Ajoutez vos vidéos dans l'ordre souhaité

⚠️ Important :

Assurez-vous que vos vidéos sont publiques ou non listées pour qu'elles soient visibles sur votre site.

2

Obtenir l'ID de votre Playlist

Une fois votre playlist créée, vous devez récupérer son ID unique.

🔍 Comment trouver l'ID :

  1. Ouvrez votre playlist sur YouTube
  2. Regardez l'URL dans la barre d'adresse
  3. L'ID se trouve après list=
  4. Copiez tout l'ID (commence par PL)
https://www.youtube.com/playlist?list=PLxxxxxxxxxxxxxxxxxxxxx
ID à copier : PLxxxxxxxxxxxxxxxxxxxxx

✅ Exemple concret :

Si votre URL est : https://www.youtube.com/playlist?list=PLrAXtmRdnEQy6nuLMOV8g4n4QjKJ4Cz1
Votre ID est : PLrAXtmRdnEQy6nuLMOV8g4n4QjKJ4Cz1

3

Modifier le Code

Remplacez l'ID de playlist dans le composant YouTubePlaylist.jsx

📝 Modifications à faire :

  1. Ouvrez le fichier src/components/YouTubePlaylist.jsx
  2. Trouvez la ligne : playlistId: 'PLYOUR_PLAYLIST_ID_HERE'
  3. Remplacez PLYOUR_PLAYLIST_ID_HERE par votre vrai ID
  4. Sauvegardez le fichier
// Dans src/components/YouTubePlaylist.jsx const playlistConfig = { // Remplacez par votre ID de playlist YouTube playlistId: 'PLYOUR_PLAYLIST_ID_HERE', // 👈 REMPLACEZ ICI videos: [ // Vos vidéos seront chargées automatiquement depuis YouTube ] };
// Exemple avec un vrai ID : const playlistConfig = { playlistId: 'PLrAXtmRdnEQy6nuLMOV8g4n4QjKJ4Cz1', // 👈 Votre ID ici videos: [ // Les vidéos seront automatiquement chargées ] };
4

Tester votre Playlist

Vérifiez que votre playlist s'affiche correctement sur votre site.

🧪 Tests à effectuer :

  1. Lancez votre site avec npm run dev
  2. Allez sur la page d'accueil
  3. Vérifiez que votre playlist s'affiche
  4. Testez la navigation entre les vidéos
  5. Vérifiez la lecture en boucle

🎉 Félicitations !

Votre playlist YouTube est maintenant intégrée sur votre site ArchiAtech avec toutes les fonctionnalités avancées !

🆘 Besoin d'Aide ?

Si vous rencontrez des difficultés, voici quelques solutions courantes.

❌ Problème : Playlist ne s'affiche pas

Solution : Vérifiez que l'ID de playlist est correct et que les vidéos sont publiques.

❌ Problème : Vidéos ne se chargent pas

Solution : Assurez-vous que les vidéos ne sont pas privées ou supprimées.

❌ Problème : Erreur dans la console

Solution : Vérifiez la syntaxe du code et que l'ID commence bien par "PL".
