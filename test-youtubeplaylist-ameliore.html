Exemple de Configuration

Voici comment configurer votre playlist YouTube avec le composant amélioré.

// Configuration de la playlist YouTube const playlistConfig = { playlistId: 'PLYOUR_PLAYLIST_ID_HERE', videos: [ { id: 'VIDEO_ID_1', title: 'Présentation ArchiAtech', thumbnail: 'https://img.youtube.com/vi/VIDEO_ID_1/maxresdefault.jpg', duration: '3:32', description: 'Découvrez nos solutions IA' } ], autoplay: 0, loop: 1, controls: 1, cc_lang_pref: 'fr', hl: 'fr' };
