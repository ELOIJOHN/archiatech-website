# Agent IA Archi - Documentation

## 🎯 Vue d'ensemble

L'agent IA "Archi" est un chatbot intelligent intégré au site ArchiAtech qui agit comme :
- **Agent d'accueil** : Premier contact avec les visiteurs
- **Support de premier niveau** : Réponses aux questions courantes
- **Pré-qualification commerciale** : Identification des besoins et opportunités

## 🧠 Fonctionnalités principales

### 1. Détection automatique du profil utilisateur
L'agent détecte automatiquement le type d'interlocuteur basé sur les mots-clés :

- **C-Level/Décideur** : ROI, croissance, stratégie, budget, performance
- **Technique/Développeur** : API, code, architecture, système, intégration
- **Néophyte** : comment, qu'est-ce que, expliquer, simple, débutant

### 2. Adaptation du discours
- **C-Level** : Langage stratégique, focus ROI et efficacité opérationnelle
- **Technique** : Langage précis et détaillé, aspects techniques
- **Néophyte** : Analogies claires, langage simple et pédagogique

### 3. Base de connaissances complète
L'agent connaît tous les services ArchiAtech :

- **Support & Déploiement IT**
- **Conseil & Intégration IA**
- **Automatisation des Workflows**
- **Solutions No-Code/Low-Code**
- **Formation & Accompagnement**
- **Transformation Digitale**

### 4. Méthodologie Archi
Application systématique du cycle de vie :
1. **Audit** : Analyse de l'écosystème actuel
2. **Stratégie** : Roadmap personnalisée
3. **Déploiement** : Implémentation progressive
4. **Support** : Accompagnement continu

## 🎨 Interface utilisateur

### Widget flottant
- Bouton rouge avec icône Bot et notification animée
- Position : coin inférieur droit
- Animation de pulsation pour attirer l'attention

### Interface de chat
- **Header** : Nom "Archi", statut "Expert IA • En ligne"
- **Messages** : Bulles différenciées (utilisateur/bot)
- **Typing indicator** : Animation de frappe
- **Input** : Zone de saisie avec bouton d'envoi
- **Contrôles** : Minimiser/agrandir, fermer

### Responsive design
- Adaptation mobile automatique
- Widget plein écran sur petits écrans
- Interface optimisée pour tous les appareils

## 🔧 Fonctionnalités techniques

### Simulation de frappe
- Effet de frappe réaliste pour les réponses
- Vitesse de frappe configurable (30ms par caractère)
- Indicateur visuel pendant la frappe

### Gestion des messages
- Historique des conversations
- Timestamps sur chaque message
- Auto-scroll vers les nouveaux messages

### Persistance de session
- Mémorisation du profil utilisateur détecté
- Adaptation continue du discours
- Contexte conservé pendant la session

## 📱 Utilisation

### Pour les visiteurs
1. Cliquer sur le bouton rouge flottant
2. Recevoir le message d'accueil personnalisé
3. Poser des questions sur les services
4. Obtenir des réponses adaptées à leur profil

### Messages d'accueil par profil
- **C-Level** : Focus sur ROI et croissance
- **Technique** : Aspects techniques et intégration
- **Néophyte** : Explications simples et pédagogiques
- **Par défaut** : Message général d'accueil
