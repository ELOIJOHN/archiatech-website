🔧 Configuration de votre Playlist YouTube

1. Créer une playlist YouTube :

  • Connectez-vous à votre compte YouTube
  • Créez une nouvelle playlist
  • Ajoutez vos vidéos dans l'ordre souhaité

2. Obtenir l'ID de playlist :

  • Ouvrez votre playlist sur YouTube
  • Copiez l'ID depuis l'URL (après list=)
  • Remplacez 'PLYOUR_PLAYLIST_ID_HERE' dans le composant

3. Configuration automatique :

  • Lecture en boucle activée (loop=1)
  • Lecture automatique configurée (autoplay=1)
  • Contrôles YouTube intégrés (controls=1)
  • API JavaScript activée (enablejsapi=1)
// Exemple d'URL YouTube avec paramètres https://www.youtube.com/embed/VIDEO_ID?autoplay=1&loop=1&playlist=PLAYLIST_ID&controls=1&modestbranding=1&rel=0&showinfo=0&enablejsapi=1
