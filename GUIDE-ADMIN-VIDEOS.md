## 🔧 **Configuration de l'API YouTube**

### **Étape 1 : Obtenir une clé API**
1. Allez sur [Google Cloud Console](https://console.cloud.google.com/)
2. Créez un projet ou sélectionnez un projet existant
3. Activez l'API YouTube Data v3
4. Créez des identifiants → Clé API
5. Copiez votre clé API

### **Étape 2 : Configurer dans l'interface**
1. Allez dans l'onglet **"Synchronisation YouTube"**
2. Collez votre clé API dans le champ
3. Cliquez sur **"Tester la connexion"**
4. Si ça fonctionne, cliquez sur **"Synchroniser les vidéos"**

## 🚨 **Dépannage**

### **Problème : Clé API invalide**
- Vérifiez que votre clé API est correcte
- Assurez-vous que l'API YouTube Data v3 est activée
- Vérifiez les quotas de votre projet Google Cloud

### **Problème : Vidéos non synchronisées**
- Vérifiez que vos vidéos sont publiques
- Assurez-vous que l'ID de chaîne est correct
- Testez la connexion API d'abord

### **Problème : Interface ne se charge pas**
- Vérifiez que le serveur de développement fonctionne
- Rafraîchissez la page
- Vérifiez la console du navigateur pour les erreurs
