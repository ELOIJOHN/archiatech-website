# 📋 Formulaire de Contact - Documentation Complète

## 🎯 **Vue d'ensemble**

Formulaire de contact moderne avec design sombre, créé en HTML, CSS et JavaScript pur. Le formulaire correspond fidèlement à l'image fournie avec une ambiance "tech" sombre et des effets visuels avancés.

## ✨ **Fonctionnalités Principales**

### 🎨 **Design Visuel**
- **Fond sombre tech** : Dégradé noir avec effets de lueur rouge/violet/bleu
- **Formulaire glassmorphism** : Fond gris foncé (#1e1e1e) avec effet de flou
- **Typographie Inter** : Police moderne pour une excellente lisibilité
- **Animations fluides** : Transitions et effets hover sophistiqués
- **Effets de lueur** : Dégradés radiaux animés en arrière-plan

### 📱 **Structure Responsive**
- **Disposition en 2 colonnes** sur desktop
- **Adaptation mobile** avec colonne unique
- **Centrage parfait** du formulaire
- **Breakpoints optimisés** : 768px, 480px

### 🔧 **Champs du Formulaire**
1. **Nom complet** * (requis)
2. **Email professionnel** * (requis avec validation)
3. **Société** (optionnel)
4. **Message** * (requis, textarea pleine largeur)

### 🎯 **Boutons d'Action**
- **Bouton principal** : Rouge vif (#e34040) "Envoyer la demande"
- **Bouton secondaire** : Gris foncé "Ou nous écrire directement"
- **Effets hover** : Élévation et animations
