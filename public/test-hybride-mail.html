🔄 Test Hybride Mail - ArchiAtech

🎯 Approche Hybride

Cette méthode essaie d'abord d'ouvrir votre application mail. Si ça ne fonctionne pas, elle copie automatiquement le message dans le presse-papiers.

📝 Formulaire de Test

🔧 Tests Individuels

📧 Comment ça marche :

  1. Essaie d'ouvrir votre application mail
  2. Attend 2 secondes pour voir si ça fonctionne
  3. Si l'app mail ne s'ouvre pas, copie le message
  4. Vous pouvez alors coller le message dans votre app mail
